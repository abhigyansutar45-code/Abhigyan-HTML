        Accessibility check

        A basic educational checker. It is not a replacement for professional accessibility testing, and it does not certify WCAG compliance.

          Four principles (WCAG)

          Perceivable
          Information can be presented in ways users can perceive.
          Operable
          Users can operate the interface with different input methods.
          Understandable
          Information and controls are understandable.
          Robust
          Content works with different assistive technologies.

          Accessibility statement

          This demo supports keyboard use, screen readers through semantic HTML and selective ARIA, reduced motion, high contrast, large text and accessible forms. It has not been formally audited, so it may contain issues. Known limitations: charts are SVG/CSS with text alternatives rather than interactive; demo data only. Send feedback to accessibility@example.com (fictional address).
