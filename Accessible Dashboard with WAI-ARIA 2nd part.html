      WCAG Principles

      Educational overview of the POUR model.

      Perceivable

      Information can be presented in ways users can perceive, including meaningful text alternatives, readable content and sufficient contrast.

      Operable

      Users can operate the interface using different input methods, including keyboard navigation.

      Understandable

      Information and controls are presented in a predictable and understandable way.

      Robust

      Content is structured so it can work with different browsers and assistive technologies.

      Help Center

      Accessibility and dashboard guidance.

      WAI-ARIA provides attributes and roles that can communicate interface semantics and states to assistive technologies when native HTML alone is insufficient.
      Use Tab and Shift+Tab to move between interactive controls. Use Enter or Space to activate buttons. Arrow keys are used by components such as tabs. Escape closes dialogs and menus where appropriate.
      Reduced motion minimizes unnecessary animation and transitions. This dashboard supports both the operating system preference and a user controlled setting.
      Use the semantic landmarks, headings, labels, table headers and accessible names. Important dynamic changes are communicated through focused status regions rather than making the entire page a live region.

      Accessibility Statement

      Accessibility Hub is an educational demonstration of accessible dashboard development.

      Keyboard support

      Important controls are designed to be reachable through the keyboard and interactive widgets expose suitable keyboard behavior.

      Screen-reader considerations

      The project uses semantic landmarks, headings, labels, table semantics, accessible names, selected states and carefully scoped live regions.

      Reduced motion

      The dashboard respects the prefers-reduced-motion preference and includes a user-controlled reduced-motion setting.

      High contrast

      A high-contrast setting strengthens the visual separation between important interface elements.

      Known limitations

      This is a demonstration project. Automated checks do not establish complete WCAG conformance. Professional accessibility evaluation should include manual review, keyboard testing and testing with relevant assistive technologies.
